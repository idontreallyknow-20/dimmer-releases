# Dimmer

Screen brightness for any monitor on Windows, including ones Windows cannot dim.

Download the latest `Dimmer_*_x64-setup.exe` from Releases. Installed copies update themselves.

- Left-click the tray icon for the slider; Ctrl+Alt+Page Down / Page Up change it from anywhere.
- Uses the monitor's own brightness when it accepts commands, otherwise dims in software, with a click-through dark layer below 50%.

This repository holds installers and the update feed only.
